# CUDA build of PyTorch for the checkmate-ai Anaconda env (Windows, Python 3.10 - 3.13).
#
# The launcher (scripts\start-checkmate.ps1) installs this BEFORE requirements.txt:
# chandra-ocr[hf] in requirements.txt needs torch >= 2.8, and the torch wheel on PyPI is
# CPU-only on Windows. Installing the CUDA wheels first keeps pip from filling the env
# with the CPU build. Manual use (inside "conda activate checkmate-ai"):
#     pip install -r requirements-torch-cuda.txt
#     pip install -r requirements.txt
# cu126 wheels need NVIDIA driver 560 or newer (first line of `nvidia-smi`).
# About 3 GB of download. Review before changing the pins: torch and torchvision
# versions must match each other.
--extra-index-url https://download.pytorch.org/whl/cu126
torch==2.14.1+cu126
torchvision==0.29.1+cu126
